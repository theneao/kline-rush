# K线狂飙

一款以真实历史 K 线回放为核心的快节奏多空交易游戏原型。玩家可以快速开仓、加仓和减仓，通过实时盈亏、连续盈利、形态识别与节奏奖励获得积分。

## 当前功能

- 美股、A 股、虚拟货币和期货标的选择
- 每局 60 根预热 K 线与 500 根比赛 K 线
- 单向净持仓、反向减仓、加权开仓均价、保证金与手续费计算
- 实时余额、仓位权益、浮动盈亏和积分反馈
- 旗形、楔形、三角形、头肩形态、双重/三重顶底及圆弧形态识别
- 图表形态连线、大阳线/大阴线动画与交易反馈特效
- BTCUSDT、ETHUSDT 各 1,000 根 Binance 4 小时历史 K 线
- 本地生涯积分、入场费与比赛结算

## 运行

项目是零依赖静态网页，直接打开 `dist/index.html` 即可。也可以在仓库根目录运行任意静态服务器，例如：

```bash
python -m http.server 8080 -d dist
```

然后访问 `http://localhost:8080`。

## 目录

- `dist/`：可直接运行和部署的游戏文件
- `.openai/hosting.json`：Sites 部署配置
- `.codex/skills/`：项目内使用的游戏开发 Skill

## 数据说明

虚拟货币回放数据来自 Binance 历史 K 线；其他市场会在浏览器端请求公开历史行情接口。数据加载失败时不会使用合成行情替代。

本项目仅用于游戏与技术演示，不构成投资建议，也不连接真实交易账户。
